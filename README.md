Release decision system

Website with Search by id, add ticket, delete ticket, edit ticket and analysis at bottom.

To add ticket you write in title, and the new ticket is given placeholder values like Severity 1, for example. You can then edit that ticket:

Edit ticket replaces the label fields when you press edit button with input fields to change everything BUT the ID of the ticket.

It is also possible to delete a ticket, click once and it will ask you to press again to delete.

On tuesday 20 october 2026 I added a filter and a sort section with buttons. If you press a filter button it shows only the tickets with that filter. While if you press sort it will display all tickets sorted in a new way (by ID, by Severity, Alphabetically, and by remaining hours). If you press it again it will show the same sort but decreased. I added a arrow on the buttons textcontent so you can see if its ascending or decreasing

At the bottom of the website is a analysis/summary that shows amount of tickets, each classification amount, total active hours and last but not least Release decision highlighted.
